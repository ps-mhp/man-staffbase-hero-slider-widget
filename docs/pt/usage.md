# Passo a passo

## Configurar o palco com uma imagem

1. Guarde primeiro a imagem na biblioteca do Staffbase. Em formato horizontal, com pelo menos
   1920 px de largura; o palco recorta-a para 21:9 ou
   4:3 — por isso, o motivo não deve ir até às bordas.
2. Coloque o widget **Hero-Slider** no topo da página, numa linha
   sem outros widgets ao lado. Se estiver numa coluna ao lado de outros
   conteúdos, não poderá ocupar toda a largura de forma adequada.
3. Abra as definições do widget. O editor de diapositivos abre-se
   automaticamente.
4. Clique em **Adicionar diapositivo**.
5. Em **Imagem**, clique na área tracejada **Selecionar imagem** e
   selecione a imagem da biblioteca multimédia. Sem imagem, o slide não será
   exibido.
6. Em **Descrição da imagem**, indique o que se vê. Deixe o
   campo em branco apenas se a imagem for meramente decorativa.
7. Insira o **Título**. Este será apresentado em maiúsculas; até cerca de
   24 caracteres, permanece numa única linha.
8. Opcional: **Subtítulo** e **Botão**. O botão só aparece
   se o texto **e** o destino estiverem preenchidos.
9. Clique em **Aplicar**.
10. Defina **Segundos por diapositivo** para `0` — no caso de um único diapositivo,
    não há nada para alterar.
11. Guarde a página e verifique-a na pré-visualização, uma vez em ecrã inteiro
    e outra numa janela estreita.

## Criar vários slides

1. Abra as definições e, com isso, o editor de slides.
2. Para cada slide adicional, clique em **Adicionar slide** e preencha-o
   tal como indicado acima. Não é possível criar mais de oito slides —
   .
3. Organize as diapositivas usando as setas **↑** e **↓** no canto superior direito. A primeira diapositiva
   é aquela que aparece quando a página é carregada.
4. Verifique se **Segundos por diapositiva** está definido em `5` (predefinição).
5. **Aplicar**, guardar e verificar na pré-visualização.

## Definir uma imagem para o formato vertical

1. Guarde na
   biblioteca uma imagem recortada na orientação vertical do mesmo motivo.
2. No editor de slides, selecione o slide em questão.
3. Em **Imagem para formato vertical**, clique em **Selecionar imagem**.
4. **Aplicar**, guardar e verificar numa janela estreita ou no
   telemóvel.

## Alterar posteriormente

1. Abra as definições do widget; o Editor de slides abre-se com
   os slides existentes.
2. Selecione, à esquerda, o slide a alterar.
3. Altere os campos à direita. Com **Duplicar**, é criada uma cópia do
   slide selecionado imediatamente a seguir; com **Apagar**, este desaparece.
4. **Aplicar** grava as alterações no widget — só depois é que
   a página fica guardada.

## Se algo não funcionar

1. **O palco permanece vazio.** Falta pelo menos uma imagem: os slides sem imagem
   não são apresentados. Abra o editor de slides e verifique se cada
   slide contém uma imagem.
2. **A imagem não ocupa toda a largura.** O widget está numa
   coluna ao lado de outros conteúdos? Nesse caso, coloque-o numa linha própria.
   Caso contrário, verifique se a opção **Mostrar em toda a largura** está ativada
  .
3. **O texto não está alinhado à linha de alinhamento.** Isto pode dever-se a uma
   largura de conteúdo diferente da página. Comunique o caso com o
   endereço da página — a apresentação adapta-se à largura que a própria página
   indica.
4. **Em vez do editor, vê um campo de texto «Folhas» com JSON.** O editor
   não conseguiu carregar. Atualize a janela de diálogo. Não edite o
   texto manualmente.
