# Schritt für Schritt

## Bühne mit einem Bild einrichten

1. Legen Sie das Bild vorher in der Staffbase-Mediathek ab. Quer, mindestens
   1920 px breit; die Bühne schneidet es je nach Fensterbreite auf 21:9 oder
   4:3 zu — das Motiv sollte deshalb nicht bis an die Kanten reichen.
2. Setzen Sie das Widget **Hero-Slider** an den Kopf der Seite, in eine Zeile
   ohne weitere Widgets daneben. Steht es in einer Spalte neben anderen
   Inhalten, kann es nicht sinnvoll über die volle Breite laufen.
3. Öffnen Sie die Einstellungen des Widgets. Der Folien-Editor öffnet sich von
   selbst.
4. Klicken Sie auf **Folie hinzufügen**.
5. Klicken Sie unter **Bild** auf die gestrichelte Fläche **Bild wählen** und
   wählen Sie das Bild aus der Mediathek. Ohne Bild wird die Folie nicht
   gezeigt.
6. Tragen Sie unter **Bildbeschreibung** ein, was zu sehen ist. Lassen Sie das
   Feld nur leer, wenn das Bild rein schmückend ist.
7. Tragen Sie die **Überschrift** ein. Sie wird in Versalien gesetzt; bis etwa
   24 Zeichen bleibt sie einzeilig.
8. Optional: **Unterzeile** und **Schaltfläche**. Die Schaltfläche erscheint
   nur, wenn Beschriftung **und** Ziel ausgefüllt sind.
9. Klicken Sie auf **Übernehmen**.
10. Stellen Sie **Sekunden je Folie** auf `0` — bei einer einzelnen Folie gibt
    es nichts zu wechseln.
11. Speichern Sie die Seite und prüfen Sie sie in der Vorschau, einmal breit
    und einmal in einem schmalen Fenster.

## Mehrere Folien anlegen

1. Öffnen Sie die Einstellungen und damit den Folien-Editor.
2. Klicken Sie für jede weitere Folie auf **Folie hinzufügen** und füllen Sie
   sie wie oben aus. Mehr als acht Folien sind nicht möglich — so weit blättert
   niemand.
3. Sortieren Sie über die Pfeile **↑** und **↓** oben rechts. Die erste Folie
   ist die, die beim Laden der Seite zu sehen ist.
4. Prüfen Sie, dass **Sekunden je Folie** auf `5` steht (Voreinstellung).
5. **Übernehmen**, speichern, in der Vorschau prüfen.

## Ein Bild für Hochformat hinterlegen

1. Legen Sie einen hochkant zugeschnittenen Ausschnitt desselben Motivs in der
   Mediathek ab.
2. Wählen Sie im Folien-Editor die betroffene Folie aus.
3. Klicken Sie unter **Bild für Hochformat** auf **Bild wählen**.
4. **Übernehmen**, speichern, und in einem schmalen Fenster oder auf dem
   Telefon prüfen.

## Nachträglich ändern

1. Öffnen Sie die Einstellungen des Widgets; der Folien-Editor öffnet sich mit
   den vorhandenen Folien.
2. Wählen Sie links die zu ändernde Folie.
3. Ändern Sie die Felder rechts. Über **Duplizieren** entsteht eine Kopie der
   gewählten Folie direkt dahinter, über **Löschen** verschwindet sie.
4. **Übernehmen** schreibt die Änderungen in das Widget — erst danach greift
   das Speichern der Seite.

## Wenn etwas nicht funktioniert

1. **Die Bühne bleibt leer.** Mindestens ein Bild fehlt: Folien ohne Bild
   werden nicht gezeigt. Öffnen Sie den Folien-Editor und prüfen Sie jede
   Folie auf ein Bild.
2. **Das Bild läuft nicht über die volle Breite.** Steht das Widget in einer
   Spalte neben anderen Inhalten? Dann setzen Sie es in eine eigene Zeile.
   Andernfalls prüfen Sie, ob **Über die volle Breite zeigen** eingeschaltet
   ist.
3. **Der Text sitzt nicht auf der Fluchtlinie.** Das kann an einer
   abweichenden Inhaltsbreite der Seite liegen. Melden Sie den Fall mit der
   Seitenadresse — die Bühne richtet sich nach der Breite, die die Seite selbst
   meldet.
4. **Statt des Editors sehen Sie ein Textfeld „Folien“ mit JSON.** Der Editor
   konnte sich nicht einhängen. Laden Sie den Dialog neu. Bearbeiten Sie den
   Text nicht von Hand.
